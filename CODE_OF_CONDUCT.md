# Code of Conduct

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep discussion technical and constructive, and do not harass anyone. Maintainers may remove comments, issues or contributions that violate this and may block repeat offenders.

To report a problem, contact the maintainer through the GitHub profile [@Venius24](https://github.com/Venius24).
